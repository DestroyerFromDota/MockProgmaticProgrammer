# Экзамен: Работа с файлами и редакторами

## Ситуация
На сервере установлен Nginx, но он не запускается.
Ваша задача - найти и исправить ошибку.

## Что нужно сделать
1. Подключись к серверу: `ssh student@localhost -p 2222` (пароль: exam2026)
2. Осмотрись в системе (команды: `ls`, `cd`, `pwd`)
3. Найди причину, почему Nginx не работает
4. Исправь ошибку с помощью редактора (`nano` или `vim`)
5. Перезапусти сервис и проверь результат

## Подсказки
- Проверь статус: `ps aux | grep nginx`
- Проверь конфиг: `sudo nginx -t`
- Посмотри подсказку: `cat /opt/hints.txt`
- Проверь себя: `/tmp/check.sh`

## Критерии успеха
- Команда `curl http://localhost` показывает страницу с текстом "Экзамен по Linux сдан!"
- Команда `sudo nginx -t` пишет "syntax is ok"

Удачи!
