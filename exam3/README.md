# Экзамен: Говорящая корова

## Ситуация
У вас есть bash-скрипт, который должен запускать говорящую корову (cowsay).
Но скрипт не работает - в нем есть 5 ошибок.

## Задание
1. Подключитесь к серверу: `ssh student@localhost -p 2222` (пароль: exam2026)
2. Найдите скрипт `/home/student/talk.sh`
3. Запустите его и посмотрите на ошибки
4. Исправьте все 5 ошибок
5. Добейтесь, чтобы корова заговорила

## Подсказки
- Запустите скрипт: `./talk.sh`
- Проверьте синтаксис: `bash -n talk.sh`
- Запустите с отладкой: `bash -x talk.sh`
- Если нужно, посмотрите подсказку: `cat /opt/hints.txt`

## Что должно получиться
Когда вы исправите все ошибки, скрипт должен:
1. Показать случайную фразу (или "Привет, мир!")
2. Нарисовать корову, говорящую эту фразу
3. Показать длину фразы
4. Написать "Успех! Корова довольна"
