# Экзамен: Отладка Python-приложения

## Ситуация
У нас есть Python-скрипт, который должен писать логи и работать с конфигом.
Но что-то пошло не так - скрипт запущен, но в логах постоянно ошибки.

## Задание
1. Подключитесь к серверу: `ssh student@localhost -p 2222` (пароль: exam2026)
2. Найдите и изучите логи приложения
3. Поймите, в чем ошибка
4. Исправьте конфигурационный файл
5. Перезапустите скрипт
6. Убедитесь, что ошибки исчезли

## Подсказки
- Логи приложения: `tail -f /var/log/myapp/app.log`
- Конфиг: `/home/student/myapp/config.yaml`
- Скрипт: `/home/student/myapp/app.py`

- Перезапуск скрипта: 
# Остановить приложение
sudo pkill -f app.py
# Запустить с правильным виртуальным окружением
sudo /opt/venv/bin/python3 /home/student/myapp/app.py &
# Проверить, что запустилось
ps aux | grep app.py
# Посмотреть логи
tail -f /var/log/myapp/app.log
