### Назначение ключевых каталогов

* **`Infra_as_code/ansible/`**  
  Содержит Ansible-плейбук для автоматической подготовки окружения. Он устанавливает Docker и Python на целевой хост, что позволяет быстро развернуть любой из экзаменов.

* **`Templates_Dockerfile/`**  
  Хранит универсальные шаблоны Dockerfile. Используются как основа для создания новых экзаменов, обеспечивая единообразие образов.

* **`exams/`**  
  Основная директория с готовыми лабораторными работами. Каждая поддиректория (`exam1`, `exam2`, `exam3`) — это отдельный экзамен, включающий:
  * `Dockerfile` для сборки образа
  * Конфигурационные файлы сервисов (nginx, python-скрипты и т.д.) с преднамеренными ошибками
  * Скрипты самопроверки и подсказки для студентов

* **`README.md`**  
  Главный файл документации с описанием проекта, требованиями и инструкциями по быстрому старту.
  
* **`Control_Docker`**    
	Прототип контейнера-менеджера. Не доделан. В разаработке

## О проекте
Этот проект представляет собой набор готовых Docker-образов для проведения практических экзаменов по Linux. Каждый экзамен — это контейнер с преднамеренно сломанным сервисом или скриптом. Студент подключается по SSH, диагностирует проблему и исправляет её.

## Используемые паттерны

### Для инфраструктуры:
- **IaC (Infrastructure as Code)** — инфраструктура как код
- **Immutable Infrastructure** — паттерн «неизменяемая» инфраструктура

### Для управляющего кода (Python 3.6+):
- **Singleton** — гарантирует существование только одного экземпляра класса

Ключевые особенности:
- Каждый экзамен в отдельном Docker-контейнере
- Доступ по SSH (студенты работают как в реальном Linux)
- Преднамеренные ошибки разной сложности
- Скрипты самопроверки
- Подсказки для студентов
- Легкое развертывание и перезапуск

Требования:
- Docker (версия 20.10 или выше)
- SSH-клиент (для подключения студентов)
- 1-2 ГБ свободного места на диске



##  Быстрый старт

### 1. Клонировать репозиторий
`git clone https://github.com/DestroyerFromDota/MockProgmaticProgrammer.git`
`cd MockProgmaticProgrammer`
`cd linux-exams`

### Выбрать экзамен (например, cowsay)
`cd exam[1-3]`

### Собрать образ
`docker build -t cowsay-exam .`

### Запустить контейнер
`docker run -d --name cow-student -p 2222:22 cowsay-exam`

### Подключиться студентом
`ssh student@localhost -p 2222`
